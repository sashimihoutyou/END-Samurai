# END-Samurai 企画書 ― とろかし流ミニゲーム・寸法二つ名

## とろかし流ミニゲームの位置づけ

世界観上の出自：こゆきが「とろかし」を使えるのは、旅立ち前に師匠・葵から流派「とろかし流」の奥伝として手ほどきを受けたためである（→「世界観・キャラクター」の葵プロフィール参照）。

とろかし流ミニゲームは通常戦闘（HPバトル）とは完全に独立した**オプショナルなミニゲーム**である。魅了敵との遭遇で「斬る！」を選び続ければ、このミニゲームに一切触れずにゲームを完走できる。踏み込んだプレイヤーだけが読みの駆け引き・Hシーン・寸法二つ名・しらせ攻略を楽しむ、**やり込み層向けの追加コンテンツ**として機能する。

設計意図：「相手の崩れどころを読んで"最後まで合わせ続ける"」というこゆきの本領（→「世界観・キャラクター」こゆきプロフィール）を、短手の選択ゲームとして表現する。カード・ゲージ管理なし。UIは温泉イベントと共用可能。

## 発生タイミング

| 場面 | 手の数 | 難易度 | 備考 |
|---|---|---|---|
| 魅了敵との遭遇イベント（雑魚） | 1手 | 易 | 「斬る！」か「とろかす…♡」を選択後に開始 |
| 魅了敵との遭遇イベント（精鋭） | 2手 | 中 | 同上 |
| しらせの「あたしと勝負して」 | 3手／ループ | 難 | 累積評価ポイント制。→「しらせのとろかし（特別ルール）」 |
| 仲間イベント（加入・親密） | 2手 | 中 | ペナルティなし（→「仲間イベントシステム」参照） |
| モモコ撃破後（中ボス） | 2手 | 中 | 通常戦闘での撃破後、窮した彼女が最後の手段として誘惑してくる（→「世界観・キャラクター」モモコプロフィール参照） |

とろかし流ミニゲームは**完全にオプトイン**。魅了敵との遭遇で「斬る！」を選べば通常の戦闘として処理される。

## 基本ルール：手の選択

### 1手の流れ

```
[相手の様子テキスト（ヒント）が1〜2行表示される]

  → ① 属性A
  → ② 属性B       ← 6属性から3つをランダム提示
  → ③ 属性C

[選択 → 相手のリアクションテキスト → 次の手、またはまだまだ！ボタンへ]
```

- **6属性：** くちづけ／ほぐし／正攻／乳繰り／後ろ取り／裏取り
- 各敵・NPCに**固定の弱点属性**が1〜2つ設定されている（→「名前持ちキャラの弱点属性」）
- ヒントテキストの「濃淡」で弱点を暗示する。直接表示はしない
- 弱点が提示3択に含まれていない場合、どれを選んでもmiss（難しい敵ほど起きやすい）

### 回数依存選択肢

一部の選択肢は、その遭遇中に何ループ目かによって出現が制限される。

| 種別 | 説明 | 例 |
|---|---|---|
| **1回目限定** | 初回ループのみ選べる。2回目以降は出現しない | 初回の膣内射精、初回口内など「初めて」ならではの演出 |
| **2回目以降限定** | 1回目には出現せず、2回目以降から選べる | 裏取り（アナルセックス）など、段階的に深まる行為 |

- 2回目以降限定の選択肢にのみ弱点が設定されているキャラクターも存在する（例：モモコの弱点「裏取り」）
- 「まだまだ！」を押さない限り解禁されない弱点があるため、まだまだ！ボタンに攻略上の実質的な意味が生まれる

## 評価ポイントと結末

### 評価ポイントの加算源

| 加算源 | 説明 |
|---|---|
| **弱点 hit** | 弱点属性を選択した場合に大きく加算 |
| **許容（near）** | 弱点ではないが、そのキャラが好む属性。中程度加算 |
| **miss** | 弱点でも好みでもない属性。加算なし（またはごくわずか） |
| **サイズ評価** | こゆきのペニスサイズが相手の好みの幅に収まるかでパッシブ加算。大きいだけでそこそこ加点、相手の求める範囲内に入ると高加点。相手の反応テキストの濃淡でほのめかされる（→「寸法二つ名システム」と接続） |
| **ループ継続** | 「まだまだ！」で追加ループを行うことで手を重ね、さらに加算できる |

### 結末分岐

全手終了後（「まだまだ！」を押さなかった場合）、積み上げた評価ポイントの合計で結末を決定する。

| 結末 | 条件 | ゲームへの影響 | Hシーン |
|---|---|---|---|
| **とろかし完了（lead）** | 評価ポイント ≥ 閾値 | 無傷で排除 ＋ 銭ボーナス ＋ 衣装修繕 | フル開放 |
| **蕩かされる（indulgent）** | 評価ポイント ≥ 最低ライン | HP中程度消費（通常戦闘1〜2ターン相当） | 短縮・攻守逆転ver |
| **失敗（抵抗される）** | 評価ポイント < 最低ライン | そのまま通常戦闘に強制移行（HP消費なし） | なし |

**とろかし中のHP0：**
とろかし中にHP0になった場合（indulgentの被ダメ蓄積や「まだまだ！」の押しすぎ等）、こゆきが射精しすぎて倒れ**「相討ち」**扱いとなる。相手にいいようにされた後、**HP10%で復活**して再開。ゲームオーバーにはならないが、HP10%で次の戦闘マスに臨む羽目になるため、HP管理の失敗として実質的なペナルティが生じる。

## まだまだ！ボタン

各ループの射精後（ポイント集計・結末決定の前）に表示されるボタン。

- **押した場合：** HPを消費し、次のループへ進む（選択からやり直し）。相手の反応テキストと地の文が変化する
- **押さない場合：** そのまま評価ポイント集計 → 結末決定
- **選択肢の扱い：** 1〜2ループ目は同じ選択肢。3ループ目以降は選択肢がランダム再抽選される
- HPコストは要バランス調整（→07「未決定事項」参照）

## しらせのとろかし（特別ルール）

しらせは神ゆえ生まれつき弱点を持たず、1回の遭遇では崩しきれない。**累積評価ポイント制**で、複数回の遭遇をまたいで少しずつ崩す長期戦になる。

### 蓄積とラン引き継ぎ

| スコープ | 内容 |
|---|---|
| **ラン内：遭遇間** | しらせとの遭遇ごとに、前回遭遇の評価ポイントがそのまま引き継がれ加算される |
| **ラン横断：50%引き継ぎ** | ランを失敗・終了した場合、次ランで前回の蓄積の**50%**が引き継がれる。しらせが初遭遇で「また会ったわねぇ……前に貰ったぶん、まだ半分ぐらいは残ってるわぁ……」とお腹をさすりながら言う |

### とろかし完了条件

- 評価ポイントがとろかし完了閾値（通常の相手の約10ループ分相当）に達した時点でとろかし完了 → しらせが仲間になる（→「あやかしイベント・しらせ仲間加入後のスキル」参照）
- 1エリアで最大2回マスを踏め、「まだまだ！」で1遭遇に複数ループを重ねられる。標準的なプレイでは2〜3エリア（4〜6回遭遇）が目安
- 祝福「絶倫」（まだまだ！のHPコスト軽減）やアイテム「女殺しの大剣」（しらせへの評価ポイント倍率上昇）で1〜2遭遇への短縮も可能。ただし大量のHP消費を伴うためそのランは厳しい戦いになる

### しらせの弱点

全属性が初期「ぜんぜん平気そう」スタート（弱点なし）。こゆきが繰り返し同じ属性を突いてループを重ねた分だけ少しずつ崩れていく。深いループほど反応テキストが変化し、しらせの「楽しい」という本音が滲み始める。デザイン上、隠す決定的な一点を持たず、"崩れなさ"自体が個性。

## 弱点属性

### 6属性の定義

| 属性 | 意味 | 特記 |
|---|---|---|
| くちづけ | キス・口を使った愛撫 | — |
| ほぐし | 前戯・丁寧な準備 | — |
| 正攻 | 正面からの挿入 | — |
| 乳繰り | 胸への愛撫・パイズリ等 | — |
| 後ろ取り | 後背位 | — |
| 裏取り | アナルセックス | **2回目以降限定選択肢。**1ループ目は提示されない |

「裏取り」は2回目以降限定のため、1ループのみの遭遇では選択肢として出現しない。弱点が「裏取り」のキャラクターは必ず「まだまだ！」を少なくとも1回押さなければ崩せない設計になっている。

| キャラ | 弱点属性 | 特記 |
|---|---|---|
| お豊 | くちづけ | — |
| 葵 | ほぐし | — |
| ふぶき | 後ろ取り | — |
| めあり | 乳繰り | — |
| 兼見 | 正攻 | — |
| モモコ | 裏取り | 2回目以降限定。まだまだ！を1回押さないと弱点に届かない |

## 寸法二つ名システム

### 概要

こゆきのペニスサイズをゲーム的に記録・表現するシステム。とろかし流ミニゲームでのサイズ評価（相手との適合度）の累積で解禁される称号（二つ名）。ゲームプレイへの直接的な影響は軽微だが、やり込みの達成感・ランクアップの手応えを担う。

### サイズ段階と評価

こゆきの「寸法」は3段階（小・中・大）で定義される（境界値は要調整→07「未決定事項」）。各キャラクターには「好みの幅（preferred range）」が設定されており、こゆきのサイズがその範囲内かどうかで評価ポイントの加算量が変わる。

- **範囲内：** 相手の求める幅に収まっていると高加点
- **範囲外（大きすぎる）：** そこそこ加点（大きいだけでも評価される）
- **範囲外（小さすぎる）：** 加点なし〜微減

どのサイズ段階にあるかはプレイヤーには明示されず、相手の反応テキストでほのめかされる（温泉イベントと同じ原則）。

### 二つ名テーブル（暫定）

弱点hit累計・サイズ評価累計でカウントし、閾値を超えると称号が解禁される。

| 二つ名 | 解禁条件（暫定） |
|---|---|
| くちづけ名人 | くちづけのhit累計が一定数以上 |
| ほぐし師 | ほぐしのhit累計が一定数以上 |
| 後ろ取り道 | 後ろ取りのhit累計が一定数以上 |
| 乳繰り上手 | 乳繰りのhit累計が一定数以上 |
| 正道一直線 | 正攻のhit累計が一定数以上 |
| 裏道開拓者 | 裏取りのhit累計が一定数以上 |
| ちょうどいい | サイズが複数キャラの好み範囲内に入った累計が一定数以上 |
| 規格外 | サイズが複数キャラの好み範囲を上回った累計が一定数以上 |

各セルの候補数・「小／中／大」の境界値は要調整（→07「未決定事項」参照）。
