### 処女フラグの仕様
- 永続フラグ `RunState.flags.otoyoDeflowered` で「処女喪失済みか」を保持。
- とろかしバトル開始時に `virgin = !otoyoDeflowered` を `CharmSetup` へ渡す（`CharmBattleState.virgin`）。
- **初挿入の発火**：処女状態で **挿入系属性**（正攻 seikou／後ろ取り ushirodori／またがり matagari／裏取り uradori）の性技が初めて命中した瞬間に `HitReaction{first:true}` を発行し、`virgin` を `false` に。前戯系（くちづけ・乳繰り・ほぐし）では処女喪失しない。
- リアクションは「初挿入 ＞ 弱点×2.0 ＞ 通常」の優先で**1命中につき1つだけ**出す（§3 と §4 が二重に出ない）。
- **とどめ＝挿入の扱い**：`とどめ`は設定上「膣内中出し」(§6-1)＝挿入そのもの。前戯のみで気力0→とどめに到達した場合、**そのとどめが初挿入＝処女喪失を兼ねる**（`TodomeUsed.first=true`）。このとき初回専用とどめ台詞 `charm.todome.otoyo.first`（初めて＋中出し＋陥落）を出して処女喪失を自然に描く。経験済みなら通常の `charm.todome.otoyo`。
- これにより**戦闘終了時には必ず処女喪失している**（＝『処女のまま進む』ルートは発生しない）。
- とどめで勝利した時点で `otoyoDeflowered = true` を永続化。

### 終了台詞の出し分け
- 処女喪失回（初回＝`virgin` で開始）：`charm.result.join`（加入イベント・二本目の発覚など、初回専用の流れ）。
- 二回目以降（再戦）：`charm.result.rematch`（発覚は無し・短い再戦台詞）。`Game.charmFirstTime` がバトル開始時の処女状態を保持して出し分ける。

### 評価メモ
- §3 の性技別反応が中核だが、α 既存の「弱点突かれリアクション」(`WeaknessReaction`) は **×2.0 弱点属性が突かれた瞬間のみ**発火し、`degradeWeakness` は段階を下げる方向にしか動かないため、お豊の×2.0弱点「くちづけ」以外は発火しない。そこで**性技命中ごとに属性別の反応を出す汎用フック** `HitReaction` を新設して §3／§4 を活かした。`WeaknessReaction`（`charm.reaction.otoyo.kuchizuke`）は弱点強調演出として残置。
- 声色は確立済みのお豊（「あたし／ばか／でしょ」口調）に合わせ、原文の「私」表記は「あたし」に正規化した。
- §4 の §4-5「キスしながらの初挿入」は対応する複合カードが無いため未マップ（複合挿入カード追加時に流用可）。
