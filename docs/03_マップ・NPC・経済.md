# END-Samurai 企画書 ― マップ・同行NPC・経済

## マップ構造

### エリア構成

3エリア制。田舎→山間部→都の順に進行する。

- 各エリア15マス。2～3本の分岐道でつながる。
- 各分岐にはタグが表示され、ルートの傾向がプレイヤーに事前に伝わる。
- プレイヤーは分岐点で刀の状態やデッキ構成に応じたルート判断を行う。
- **仲間は特定ルートに固定配置される（→「同行NPCシステム・出現と加入」参照）。** 全仲間と1ランで遭遇すること自体は可能だが、そのルートが過酷であったり加入条件が難関であったりする。

### 分岐タグ

各分岐道に1～2語のタグがアイコン付きで表示される。プレイヤーはタグを見て刀の状態やデッキ構成に基づいた判断を行う。

タグの例：
- 「獣道」→ 獣系の敵が多い、道具カードの報酬が出やすい
- 「旧街道」→ 人型の敵が多い、技カードの報酬が出やすい
- 「けもの小道」→ 敵が弱いが野営地が出ない
- 「霧の道」→ しかばね系が多い、通貨報酬が多い

### マス配置

- **4マス目、9マス目、14マス目：** 野営地（確定出現）。同行仲間がサービスを提供する。ただし「けもの小道」タグのルートでは野営地が出現しない場合がある。
- **15マス目：** エリアボス（確定出現）。
- **その他のマス：** 戦闘、イベント、ランダム遭遇など。移動中の同行仲間による簡易サービスが利用可能。
- **都・5マス目：** モモコが中ボスとして全ルート確定出現（→「敵デザイン・モモコ」参照）。

分岐を考慮すると、1ルートあたり実際に踏むマスは7～9程度。

### 野営地

こゆき一行が足を止めて野営する場所。同行仲間がサービスを提供する。

**第1・第2エリアの野営地：** 同行仲間の施設に加え、無名NPCが一部施設を補う（偏り防止ルール：前回出なかった施設カテゴリが優先的に無名NPCとして出現）。

**第3エリア（都）の野営地：** 都は生存者ゼロの設定のため、野営地は無人の「廃墟の野営跡」となる。無名NPCは出現せず、**同行している仲間からのみ支援を受けられる。** 鍛冶屋（お豊）はプロローグで確定加入する幼馴染のため、通常は都でも刀修繕・パーツ購入が可能。

施設の対応：
- **鍛冶屋（お豊同行時）：** 刀の完全修繕、パーツ（部位交換カード）の購入、衣装の修繕（有償）。
- **道場（葵同行時）：** 技カードの処分（デッキ圧縮）・購入。仲間アクティブカードは処分対象外（忘れられない）。
- **ショップ（兼見同行時）：** 道具カードの購入・売却。
- **めありの祈り場（めあり同行時）：** 祈りイベント＋祝福付与（→「祝福システム」参照）。

### ランダムイベント

道中マスで発生する可能性がある。

- 休息地（HP回復）
- 遭遇（戦闘 or 交渉）
- セクシー系イベント：温泉（→「温泉イベント」参照）、あやかし（→「あやかしイベント」参照）、衣装破損イベント（→「衣装破損システム」参照）。
- 魅了敵との遭遇イベント（→「魅了バトル・魅了敵との遭遇イベント」参照。通常戦闘マスが確率で上書きされる）。
- こゆき固有イベント：「仲間イベント（加入イベント・親密イベント）」「秘密バレかけイベント」（→各セクション参照）。
- 仲間の救済遭遇イベント（→「同行NPCシステム・出現と加入」参照）。

## 同行NPCシステム

### 概要

道中で出会ったNPCがこゆきの旅に同行し、仲間になる。ころりん耐性の噂を聞いて「こゆきの近くにいれば安全だ」と判断してついてくる者たちが大半。同行仲間は移動中の簡易サービス、野営地でのサービス、戦闘中のパッシブ＋アクティブ援護、道中のガヤ会話を提供する。

### 出現と加入

**固定ルート配置（基本）：** 各仲間は第1・第2エリアの特定ルート上に固定配置され、そのルートを通れば必ず遭遇する。仲間同士の二者択一は発生せず、全仲間と1ランで遭遇すること自体は可能（ただしそのルートが過酷だったり加入条件が難関だったりする）。遭遇時にイベント（戦闘、アイテム/金銭要求、魅了バトル開始など）が発生し、クリアすると加入する。

**確定遭遇枠（対象外）：** 以下は救済対象外（必ず会えるため）。
- **お豊（鍛冶屋）：** こゆきの幼馴染。ゲーム開始時（プロローグ）の魅了バトル・チュートリアルを経て確定加入する。以後は最初から同行しており、未加入のケースは発生しない。
- **ふぶき（山賊大将）：** 第2エリアボス。撃破後に加入。
- **モモコ（おんな鼠小僧）：** 第3エリア（都）5マス目の中ボスとして全ルート確定出現。撃破（魅了→気力0→「とどめ！」）で改心・加入。
- **しらせ（あやかし）：** 各エリアに固定3マス、1ランで最大2回踏める固定イベント（3エリア×最大2回＝最大6回遭遇可能）。「あたしと勝負して」に勝てば加入。

**救済イベント（取りこぼし対策）：** ルート配置の仲間のうち、ルートを通らずに加入できなかった者のみ、後にランダムイベントで再登場し、同行する可能性がある。確定遭遇枠（お豊・ふぶき・モモコ・しらせ）は対象外。しらせは遭遇機会が十分（最大6回）あるため救済せず、自力で勝つ前提とする。代わりに、しらせを倒しやすくするための要素（開発システムによる弾力的攻略等）を別途設ける（→「しらせ攻略救済」参照）。

### 仲間スキル

各仲間は「常時/毎ターン発動の弱いパッシブ」と「デッキに加えられる強いアクティブカード」の2つを同時に持つ。

**パッシブ：** 常時または戦闘開始/終了時に自動発動。効果は弱め。多くは好感度に比例して効果量が増加する。仲間が増えるほどパッシブが積み上がるため、仲間収集が線形に報われる。

**アクティブ（特殊道具型カード）：** デッキに加えて使う切り札。戦闘中1回のみ使用可能（使用後その戦闘中は再使用不可）。戦闘終了後にデッキへ戻り、消費・破棄されない。通常の技カード同様にデッキ編成で投入できるが、道場で「忘れる」ことはできない。仲間はずっと同行しているため「ボスまで温存」を考える必要はなく、各戦闘で気軽に切れる切り札という設計。

**バフのスタック上限：** 攻撃力・防御値バフは内部値±99まで保持可能（実際の有効レンジは概ね-4〜+6を想定）。連撃率バフは上限を設ける（暫定+30%）。複数系統からの同種ボーナスは加算で合算する（→「ボーナス加算の一本化」参照）。

| 仲間 | パッシブ | アクティブ（戦闘中1回／AP） |
|---|---|---|
| お豊（鍛冶屋） | 鍛えの目：戦闘開始時、防御値+（好感度比例：低1／中2／高3） | 打ち直し（AP3）：この戦闘中、攻撃力+2・防御値+2。さらに刀部位デバフを1回無効化 |
| 葵（師範） | 見取り稽古：戦闘開始時、手札の技カード1枚を一時的に1ランク上の技に置換（好感度高で2枚） | 型稽古（AP2）：この戦闘中、技カードのAP-1（最低1）。さらにこのターン、連撃率+（低5／中10／高15）% |
| 兼見（商人） | そろばん勘定：戦闘終了時、通貨+（低10／中20／高30）% | 掘り出し物（AP1）：道具カードを1枚山札から手札へ引き寄せる。さらにこの戦闘中、道具カードの残り回数を消費しない |
| めあり（シスター） | ぜずのご加護♡：戦闘開始時、ランダムな祝福効果を1つ一時付与（好感度高で2つ） | 臨時のおつとめ♡（AP2）：HP（低5／中8／高12）回復。さらに魅了中の敵がいればその気力に追加ダメージ小 |
| ふぶき（山賊大将） | 先手必勝：戦闘開始時、全敵にダメージ（低1／中1＋ランダム1体出血1／高2＋ランダム1体出血1） | 気合入れ（AP3）：この戦闘中、攻撃力+（低2／中3／高4）。さらに次に受ける気絶・掴みを1回無効化 |
| モモコ（おんな鼠小僧） | 盗み見：戦闘開始時、中央ブラインド枠の内容が見える（好感度高でブラインド枠のレア率+10%） | 目くらまし（AP2）：敵1体を1ターン気絶（ボスは出血3に変換）。さらにこの戦闘中、連撃率+（低5／中10／高15）% |
| しらせ（あやかし） | 畏れ：戦闘開始時、ランダムな敵1体を1ターンスタン（好感度高で全敵） | 水底へ（AP3）：敵全体に防御無視の固定ダメージ（低2／中3／高4）。さらに魅了中の敵がいればその気力を大きく削る |

※めあり・しらせのアクティブにある「魅了中の敵がいれば」は、魅了バトル中に仲間アクティブを切れる設計の場合に機能する。魅了バトルにおける仲間アクティブの可否は実装時に確定する（未決定事項参照）。

### 好感度システム

各仲間は好感度値を持ち、パッシブ効果量（および一部アクティブ効果量）に比例して反映される。便宜上「低/中/高」の3段で記述するが、内部的には連続値でもよい。

**好感度の上昇トリガー：**（→「仲間イベントシステム」参照）

| トリガー | 上昇量（暫定） | 備考 |
|---|---|---|
| 加入イベント（耐性付与） | 大 | 加入時1回。好感度初期値を確定させる |
| 親密イベント成功 | 大 | 固有レアも同時獲得 |
| 親密イベント失敗 | 微増 | ペナルティなし。再挑戦を促す |
| 一夜の相手 | 中〜大 | 毎日ランダム抽選。複数同時上昇あり |
| 仲間アクティブカードの使用 | 微増 | 連打でカンストしない程度 |

「アクティブ使用で好感度微増→パッシブ強化→さらに使いたくなる」という正のループを意図。ただし上げ幅は小さく抑える。

### しらせ攻略救済

しらせは加入機会が十分（最大6回遭遇）あるため加入の救済は行わないが、「会えるが勝てない」という固有の壁に対し、倒しやすくする救済を設ける。

- **開発システム（個体永続・ラン固有）による弾力的攻略：** しらせの弱点は固定開示されず、開発システムで弱点を耕すほど有利になる。開発度はしらせ個体に永続するため、勝てなくても同属性を突き続ければ遭遇を重ねるうちに弱点化していく（数値・初期弱点・必要命中回数の詳細は→「魅了バトル」の開発システム／しらせの初期弱点を参照）。これがしらせ攻略の主軸となる。
- 永続バフ方式（敗北/勝利累計で与気力ダメージ+等）は祝福・部位強化との加算でインフレしうるため採らず、開発システムへ一本化する。

### 移動中の簡易サービス

同行仲間は移動中（野営地以外のマス）でも簡易サービスを提供できる。野外で設備が整わないため、野営地での完全版より制限がある。

| 仲間 | 簡易サービス | 制限 |
|---|---|---|
| 鍛冶屋（お豊） | 1部位のみ1段階回復（無償） | 1マスに1回、1エリアにつき合計2回まで |
| 師範（葵） | 手札の技カード1枚を捨て札に送って別の技カードを1枚引く | 1マスに1回 |
| 商人（兼見） | 道具カード1枚を定価で売却可能 | 1マスに1回 |
| めあり | 簡易サービスなし。ガヤ参加のみ | — |
| おんな鼠小僧（モモコ） | ランダムで道具カード1枚を無償で入手（盗んでくる） | 1エリアにつき1回 |

### ナラティブ上の進行

- **第1エリア：** こゆきは幼馴染のお豊と二人旅（お豊はプロローグで加入済み）。道中ルートでNPCと遭遇し、1人ずつ仲間が増えていく。「あたしについてきても何も出ないぞ」「ころりんにかからなくなるならそれでいいんだよ」
- **第2エリア：** 噂が広まり、人が集まっている。「こゆきの近くにいれば安全だ」と信じてついてきた者たちが小さなキャラバンを形成する。加入済み仲間との親密イベントが発生しうる（→「仲間イベントシステム」参照）。ふぶきがボスとして登場し、撃破後に加入（温泉イベントの延長で加入イベントが発生）。
- **第3エリア：** こゆき一行は賑やかなパーティーになっている。都は無人で、支援は仲間頼み。5マス目でモモコと再会・加入。最終ボス前に仲間たちが激励してくれる演出が入る。

### 道中ガヤ会話

戦闘以外のマスに到着するたびに、同行仲間の中からランダムで1人が短い台詞を発する。台詞はカテゴリ別にプールを用意し、状況に応じて抽選する。

**汎用（移動中いつでも）：**
- お豊：「ちょっと、刀鳴ってるじゃない。手入れしなさいよ」「この辺の鉄、質が悪いわね」
- 葵：「姿勢が崩れてるよ」「足音を立てすぎ。斬られるよ」
- 兼見：「この辺に宿はないのかなぁ……」「あ、あれ売れそう」
- めあり：「ニホンノ田舎、キレイデスネー」「ぜずさまはドコニデモいらっしゃいマス♡」
- ふぶき：「この道、昔シマにしてたな」「腹減ったな、ちびっ子」
- モモコ：「この辺、蔵がないね。つまんない」「あたしに盗めないものはないよ。……心以外はね」

**しかばねについて（戦闘後）：**
- お豊：「……あの刀、打ちは悪くなかったわね。持ち主が気の毒」
- 葵：「しかばねの動き、型がないのに厄介だね。生前の癖が出るのかな」
- 兼見：「しかばねの持ち物って売っていいのかな……いや、持ち主もういないし……」
- めあり：「シカバネにもぜずさまのオ救いハアルノデショウカ……マアイイデス！」
- ふぶき：「元は人間だ。……忘れんなよ、ちびっ子」
- モモコ：「しかばねの懐は漁らないよ。……さすがにね」

**こゆきとの関係を匂わせる（ころりん耐性付与イベント済みの場合のみ）：**
- お豊：「……昨夜のことは誰にも言わないから。だから顔を赤くしないでよ」「こゆき、今夜も刀の手入れ……べ、別に、なんでもない！」
- 葵：「こゆき、昨夜の稽古の復習はした？　……どっちの、とは言わないけれど」「特別稽古、またつけてあげようか？　……夜の、ね」
- 兼見：「こ、こゆきさんの近くにいると安心……いろんな意味で……」「今でも信じられないんだけど……あれ、本当に……（こゆきに睨まれて黙る）」
- めあり：「コユキチャンのカタナ、今日モ元気デスカ？♡ ドッチモ♡」「昨夜ノお祈り、とてもヨカッタデス♡ またシマショウネ♡」
- ふぶき：「お前のあの刀、なかなかの業物だったな……ふふ」「ちびっ子、今夜は酒でも飲むか。……あとは、まあ、流れで」
- モモコ：「あんたにヤラれたのは初めてだよ……いろんな意味で」「あたしを仲間にしたのは正解だね。……いろんな意味で」

**こゆきの返し：**
- 関係匂わせ台詞への返し：「……黙れ（赤面）」「……次はない（目を逸らしつつ、次がある）」「…………（無言で歩く速度を上げる）」
- 通常台詞への返し：基本無言だが、稀に「……そうか」「……知らん」程度の短い返答。

## 経済システム

### 通貨

- 敵撃破時に獲得。
- 戦闘報酬画面の左右選択枠に通貨が出現することがある（カードの代わりに通貨を取る選択）。
- 不要カードの売却でも資金を得られる（同行商人の簡易サービスで移動中も可能）。
- エリアごとに物価が上昇する設計でインフレを抑制する。

### ボーナス加算の一本化

同種のボーナスは系統を問わず加算で合算し、基礎値へ一括適用する。後のバランス調整を容易にするため、ボーナスの源を独立計算しない。

- **通貨ボーナス：** 兼見パッシブ、めありの祝福「めありのおこづかい」、救済者カウント、ころりん耐性強化等を加算。合算+50%でキャップ。計算例：基礎100G ×（1＋0.30＋0.10＋0.05）＝145G
- **防御値ボーナス：** お豊パッシブ＋お豊アクティブ＋祝福「ぜずのかご」＋救済者バフ＋みらくるがーど等を加算プールに統合。
- **攻撃力ボーナス：** ふぶきアクティブ＋祝福「じゅうじか」等を加算（有効レンジ目安-4〜+6、内部±99）。
- **連撃率ボーナス：** 葵/モモコアクティブ＋祝福「ぐれーす」＋大破ボーナス等を加算（上限+30%確定）。

**通常戦闘の与ダメージ計算式そのもの**（加算プールを基礎値へ適用しカード倍率を掛ける式・敵防御値の実数値減算・「崩し」による敵防御値削減・部位デバフ発生確率・基準値）は→「カード・刀・戦闘」の「戦闘の数値モデル」に集約する。本セクションは経済システム側の加算一本化方針のみを示す（重複記載を避ける）。

**与気力ダメージ（魅了バトル）の加算一本化：**

魅了バトルの与気力ダメージも本方針に従い、加算系（部位パラメータの威力・祝福「ぜずのよがり」等）をすべて合算してから開発倍率（×0.5〜×2.0）を掛ける（倍率の二重掛けはしない）。同様に、四十八手被ダメージ軽減＝こゆきの「守り」も被ダメージ側の軽減プールへ加算統合する。

**計算式・敵の気力防御の減算順序・裏取りの2倍参照・乳繰りの回復係数・連撃による開発加速など、魅了バトルの数値モデルそのものは→「魅了バトル」の「気力防御パラメータと回復・貫通の数値モデル」に集約する（重複記載を避け、本セクションは経済システム側の加算一本化方針のみを示す）。**

### 戦闘報酬

戦闘終了時に3枚のカードが提示される。

- **左枠・右枠：** 内容が表示される。稀に通貨が出現。
- **中央枠：** 内容非表示（ブラインド）。1ランク上のカードが出やすいが、下振れやカテゴリ外れ（技が欲しいのに道具が出る等）のリスクがある。
- 3枚すべてを拒否することも可能（デッキ膨張防止）。
