# END-Samurai ― テストで見つけた改善箇所（α版プレイ評価と改修記録）

本書は、α版（ブラウザ先行プロトタイプ）を実際にプレイ・コードレビューして得た**「まだ面白くない」原因の評価**と、それに基づく**改修の判断・実施内容・先送り事項**を記録する。設計（01〜07）と実装仕様（08）に対する「現物がどう動いているか／何が足りないか」のフィードバック層であり、ここで確定した変更は各設計文書へ反映する。

> 評価の前提：α版の主問い①「刀メンテ＋デッキ構築の通常戦闘ループは面白いか」を最優先に見る。個々のシステムは設計どおり動作している（Core/UI分離・決定論RNG・データ駆動・刀3部位・予告/受け/いなす）。問題は**「成長」と「緊張」と「選択の重み」の循環が一本も繋がっていない**点にあった。

---

## 1. 評価（なぜ面白くないのか）

実装の実数値（`combat-config.json` baseAp=4 / baseMaxHp=30 / baseBladeAttack=6 / baseTsubaDefense=3、`cards.json`、`enemies.json`、`maps.json`）に即した診断。効くもの順。

### 1-1. デッキ構築の"エンジン"が存在しない（最重要）
- **ドロー／コンボがない。** 毎ターン手札を5枚補充するだけで、デッキ枚数が戦術に影響しない＝構築の動機が弱い。
- **スケーリングする軸が一つもない。** 永続バフは仲間アクティブ（1戦闘1回）だけ。`bonusPools`（攻撃/防御/連撃）という箱はあるのに、積み上げる手段がなかった。
- **プレイヤーが状態異常を扱えなかった。** `poison`/`bleed`/`stun` は実装済みで敵→こゆきには飛ぶのに、**プレイヤーの全カードに敵への `apply_status` が無く**、毒/出血ビルドという王道シナジーが死んでいた。
  - 補足：実装上、`poison` は「こゆきのAPを下げる」処理しか持たず**敵には無害**。一方 `bleed` は敵にもDoTが入る（`tickBleed` が全敵をなめる）。したがって**プレイヤー側のDoT軸は出血が正解**。
- **デッキが育たない。** ドロップ候補が5枚・レアリティ/強化/除去報酬なし。終盤デッキも序盤とほぼ同じで「強くなった」手応えが出ない。

### 1-2. 緊張がゼロ（死なないので選択が軽い）
- 最大HP30固定・回復過剰（休息+8／野営+5／温泉全回復／きずぐすり）で、敵の攻撃4〜7に対しほぼ負けない。
- **刀劣化＝中核のはずが無害化**：削るのは狙撃型2体だけ、部位を予告し、受け切り/見切り/いなすで確定防御でき、野営地・休息・温泉で無償フル打ち直し。stage補正も小さい。メンテが駆け引きの主役になっていない。

### 1-3. 敵・エンカウンターが平坦
- 6アーキタイプ中、実装は cyclic と sniper の2つだけ。全敵が「2手をループする予測可能な雑魚」。
- ボス（大しかばね）は打撃7/掴みのcyclic＝大きい雑魚。フェーズも脅威の山場もなく、クライマックスが無い。
- 道中で攻撃力が伸びず、ランを通したジリ貧が一度も起きない。

### 1-4. マップに意味のある選択がない
- 3分岐がどれも「戦闘A or 戦闘B」で、情報も見返りも差がない＝ルート取りが「どっちでもいい」。リスク/リターンの分岐が存在しない。

### 1-5. 報酬・経済が薄い
- 銭を使う切実さがない（無償回復・無償打ち直しが多い）。良パーツ（30〜60）に対し稼ぎ（~100）も乏しく、経済が「機能はするが効かない」。

## 2. 今回の改修（このコミットで実施）

評価の **1-1（構築軸）／1-3（クライマックスと読み合い）／1-4（ルートの重み）** に、既存スキーマ・既存テストを壊さない範囲で着手した。最も費用対効果の高い「プレイヤーに伸びる軸を渡し、それに見合う脅威を置く」を優先。

### 2-1. 構築軸を3本立てる（新カード）`src/data/cards.json`
| ID | 名前 | コスト/効果 | 開く軸 |
|---|---|---|---|
| `kirisaku` | 斬り裂く | AP2・攻撃×0.6＋**敵に出血x3付与**（スタック加算） | **出血DoT軸**（重ねるほど終盤に効く） |
| `seigan` | 正眼の構え | AP1・**攻撃力+2（この戦闘中ずっと・積める）** | **スケーリング軸**（`bonusPools.attack`を育てる） |
| `iai` | 居合 | AP2・攻撃×2.0・**前ターン未行動が条件** | **溜め払い軸**（1ターン捨てて大ダメージという択） |

- いずれも既存の effect 種別（`apply_status`/`buff_attack`/`attack`＋`requirements`）で表現でき、エンジン改修不要。
- `rewards.json` のドロップ候補と、道場（`shops.json`）の在庫に追加。デッキ報酬の幅と「育てる動機」を確保。

### 2-2. ボスをクライマックスに刷新＋新アーキタイプ実装 `src/data/enemies.json` / `src/core/rules/normal-battle.ts`
- **`random_intent`（予告ランダム型）をCore層に実装**（設計済みだが未実装だった4型のうち1つを解禁）。
  - 仕様：**表示中の予告＝この敵ターンに必ず実行される行動**。実行後に次ターンぶんを抽選し直す（予告とのズレを作らずフェアに読み合いをさせる）。`startBattle` で初期予告を抽選、`endTurn` の行動後に再抽選。
- **大しかばね（ボス）**：cyclic → **random_intent**、HP 32→**40**、行動に **ぶちかまし（11ダメージ）** を追加（打撃7／ぶちかまし11／掴み）。何が来るか読めない重い相手になり、`受ける/見切る`の判断が毎ターン生きる。
- **亡霊武者（`akuryo_musha`／新エリート）**：random_intent・HP26・防御2・懸賞金22。薙ぎ9／刺し貫き（出血）／大上段（柄狙い・部位破壊）を不規則に振る。防御を抜く攻撃と部位狙いを併せ持つ、田舎の山場。

### 2-3. ルートに重みを与える（リスク/リターン分岐）`src/data/maps.json`
- 谷間の野営地（`c_camp1`）から **任意の強敵分岐「旧戦場跡（亡霊武者）」（`c_elite`）** を追加（既存の `start` 分岐はテスト維持のため不変）。
- エリートは**懸賞金が高い（22）**＝より良い刀パーツ（30〜60銭）に手が届く。「踏んで強化を狙うか、HPを温存して避けるか」という既存システムだけで成立するルート選択を作った。

### 2-4. テキスト `src/data/text.json`
- 新カード3種のフレーバー、亡霊武者の遭遇文を追加。大しかばねの遭遇文を「読めない重い相手」に更新。

### 2-5. テスト `test/build-axes.test.ts`（新規・7件）
- 出血付与→DoT、正眼の攻撃積み、居合の前提条件と威力、random_intent の「予告＝実行」一致、ドロップ/エリート配線を保護。**全130件green**。

## 3. 先送り（次の改修候補・優先度順）

今回は範囲を絞った。残る評価項目は次イテレーションで扱う。

1. **緊張の設計（1-2）**：無償フル回復（特に温泉全回復）をトレードオフ化／回数制限化、最大HPを成長要素化、劣化を避けにくい敵（部位を予告しない削り）を追加。← 今回プレイヤーを強化したぶん、ここを締めないと簡単化に振れる懸念がある。**最優先**。
2. **残りアーキタイプ**：`timed`（時限）/`concealed`（隠匿・くびなし）/`synergy`（連携）の実装。`random_intent` と同じくデータ駆動で追加可能。
3. **構築の深掘り**：カード強化（+版）・除去報酬、毒を「敵にも効くDoT」に拡張するか方針決定（現状は対プレイヤー専用）。
4. **マップ生成**：固定1パターン→分岐の非対称化（戦闘/店/休息など性質の違う選択肢）。本番Godotでのランダム生成に接続。
5. **ボス第二形態/ギミック**：HP閾値でパターン変化など、random_intent の上にもう一段の山場を。
